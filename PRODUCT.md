# Product
<!-- impeccable:product-schema 1 -->

## Platform
adaptive

## Users
The owner uses 2du to organize daily tasks, work, notes, and thoughts across phones and a computer.

## Product Purpose
A local-first personal workspace that remains useful offline and can be operated by an external AI agent.

## Capabilities and Constraints
Expo SDK 54, React Native, Expo Router, SQLite, Zustand, NativeWind. Preserve existing tasks, notes, reminders, backups, and date views. Add optional self-hosted username/password sync, revocable agent API keys, customizable calendars, and responsive desktop web.

## Brand Commitments
User requests the visual language of https://autismaxer.quest/: warm dark ground, editorial serif headings, restrained colored accents. Apple-style spacing, feedback, and accessibility.

## Open Decisions
Confirmed by the owner: personal accounts, no team sharing. Hosting domain and supported slowest physical device are unspecified.
